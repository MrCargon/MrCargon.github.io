3D Simulation 2026

Solar System Simulator

3D solar system in Three.js with hand-written GLSL shaders: an Earth that blends daylight and night-side city lights across the terminator, an atmosphere glow and a Sun corona. Zoom into Earth and a level-of-detail system fades in states and cities, while a tile engine streams street and satellite maps. It picks the zoom from what the camera sees, holds it inside a deadband so it does not re-download at level edges, keeps its caches bounded and cancels downloads the camera no longer needs. Live ISS and earthquake data go through a small fetch wrapper with a cache, a timeout and a circuit breaker, so one dead feed cannot break the globe. Orbits solve Kepler's equation. The service-worker cache name is a hash of the deployed files, so a new deploy reaches returning visitors. Code references: README, Engineering case study.

Multiplayer Game · in development 2026

Unknown Underworld

An online co-op dungeon game in Godot, built server-first: the client never decides anything, it talks through a gateway to separate auth and game servers, and the game server owns every hit, pickup and enemy move. Enemies do not use an aggro radius; each one has a leaky-integrator awareness that builds while it senses you and fades when you leave, so it can be calm, hunting or searching the last place it saw you, and a pack wakes up one by one instead of in unison. Floors are dressed by seeded generator code. Playtest builds run with test bots; the source is private while it is in development.

Simulation 2026

Artificial Life: Lenia, Conway & Particles

🧬 Open Simulation

Three artificial-life simulations on one page, all computed at runtime with no images, textures or audio files. Lenia: continuous cellular automata as a GPU shader, where organisms with real boundaries emerge from one convolution and a growth curve. Conway: the discrete Game of Life and any of its 262,144 birth/survival rules. Particle Life: no grid at all, just particles that pull and push each other by an interaction matrix you can edit, with density regulation so clusters stay alive instead of collapsing. Zoom, pan, draw and edit the palette in every mode.
